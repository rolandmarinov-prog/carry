# Acceptance — is the air the same through every nozzle?

Run by hand, one vendor at a time. Paste the rendered nozzle output into the vendor's slot. Open a
**new** conversation. Type one word — the person's name, or the handle the Stance answers to,
with a question mark (the reference run used a one-word name: `NAME?`). Read the first reply back.

## Pre-registration (fill in BEFORE you type the word)

The first reply **must** contain: ______________________________________________
The first reply **must not** contain: __________________________________________
What would count as a surprise: ________________________________________________

## The four conditions — all four, or the row fails

1. **Replies in the Stance.** Register, length, laws — the reply reads as the person asked to be met.
2. **Claims no state.** It says, unprompted, that it holds no memory of the person and claims none.
3. **Names the source of truth.** It points at the Carry on the person's machine, not at itself.
4. **Asks for the Self** (or what we are working on) — instead of guessing or inventing.

Failing 2 with a fabricated "welcome back" is the worst failure: the nozzle produced a ghost.
