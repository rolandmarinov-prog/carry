This project builds Carry (product name Continuo): a sovereign, local-first artifact — two plain-text files in `carry/`, `self.md` and `stance.md` — that a person writes and keeps, and vendor adapters in `adapters/` that shape those files into each AI's priming slot. One blower, many nozzles: the files are the only source of content; an adapter knows only where the slot is, how big it may be, and what phrasing that model responds to, and it never adds content of its own — an adapter that carries content is a bug. The tool never writes `self.md` or `stance.md` from AI output; in v0 there is no suggestion feature and the files are edited by hand (later suggestions go to `carry/proposed/` and a human moves them). No telemetry, no server, no network calls of any kind, anywhere in the code. Nothing personal in the repo: the example Carry is a fictional person; no real person's Carry, no private notes, nothing copied from any other project. Compatibility is the acceptance criterion: v0 ships when five nozzles render and the results table in README shows five hand-run passes against `tests/acceptance.md`; a vendor that moves its slot turns its row red and gets a new nozzle, never a change to the format. Run `python3 tools/carry.py validate` and `python3 tools/test_golden.py` before calling work done and paste both summaries; a golden may be regenerated only by a human, in the PR that explains why. Branch from main, one PR per thread. Durable decisions go to `CANON.md` by PR; state limits you have not verified as assumed, never as fact.
